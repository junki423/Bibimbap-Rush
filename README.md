# Bibimbap Rush

Bibimbap Rush is a cooking game made with HTML, CSS, and JavaScript.

## How to Play

- Click the Play button to start.
- Read the customer's order.
- Drag the correct ingredients into the bowl.
- Cook the egg and galbi in the mini game.
- Press Done to receive tips based on accuracy and speed.

## Features

- Random customer orders
- Drag and drop ingredients
- Timer system
- Egg and galbi cooking mini games
- Tip and result system
- Background music and sound effects
